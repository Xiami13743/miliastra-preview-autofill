# 千星奇域-预览信息-一键填写

Windows / Python 标准库 / tkinter · v0.3.7

[![简体中文](./assets/readme-zh.svg)](./README.md) [![English](./assets/readme-en.svg)](./README.en.md)

从 Excel 填写原神千星奇域关卡的多语言预览信息，并辅助选择封面、展示图及视频。默认中文，可切换 English。

## 功能

- Excel 表头自动识别15种语言；字段行2/9/12/16分别为关卡名称、玩法说明、关卡描述、版本更新记录。
- 导出含字段说明与示例的 xlsx 模板，无需 openpyxl。
- 全选后通过剪贴板粘贴文字，F9随时中断；每格错误写入日志。
- 选择游戏首行的默认语言后，自动换算 15 种语言的落点。顶部 9 行与底部 6 行各有定位锚点，每次换屏核对语言顺序。
- 内置 v0.3.6 的文字和媒体坐标。16:9 窗口可直接检查位置，再按需微调。
- 封面、0～4张展示图、1个可选视频；支持复制文件或路径后Ctrl+V。路径右对齐显示文件名。
- 物理像素与 Per-Monitor-V2 DPI 感知，按客户区比例存坐标，记录分辨率和缩放。

## 使用

便携版：完整解压 Windows x64 便携包，双击 `千星奇域-预览信息-一键填写.exe`，不需要安装 Python 或 Excel。请保留同目录的 `_internal` 文件夹。校准文件保存在 exe 旁边，更新时可保留。

源码版：安装 Python 3.10 或以上（含 tkinter），下载仓库 ZIP 并解压，双击 `启动-千星奇域-预览信息-一键填写.cmd`。两种版本都会请求管理员权限，以向管理员运行的游戏发送输入。

### 文字

1. 点「导出 Excel 模板」，在对应语言列填写第 2、9、12、16 行。替换示例并保留表头，首次发布时清空第 16 行示例。保存后点①打开，选择工作表、要填的语言和字段。
2. 在原神进入关卡详情页的多语言设置。若语言未齐，用「添加语言 → 全选」启用 15 种语言。滚到顶部，在「游戏首行（默认语言）」中选择第一行带「默认」标记的语言。工具将它排到首行，其余按游戏语言顺序排列。右上角 **Language** 用于切换工具界面。
3. 点④检查位置，核对顶部、底部的语言顺序和鼠标落点。落点偏移时点③校准。点击「采集当前点」后，在五秒内将鼠标停在指定单元格、图标或保存按钮的**中心**。英文游戏的编辑弹窗保存按钮是 **OK**。
4. 核对后点⑤填写，检查内容，再到游戏里手动提交。F9 可随时停止。
5. 更新已发布关卡时，可勾选「版本更新记录」。如果版本下拉里的目标与预设位置不同，用③重采版本选项。

表格可使用 `模板/多语言填写模板.xlsx` 或工具导出的模板；保留语言表头，替换对应字段行示例。支持语言：简体中文、繁體中文、English、한국어、日本語、Español、Français、Русский、ภาษาไทย、Tiếng Việt、Deutsch、Indonesia、Italiano、Português、Türkçe。

可以在字段之后添加关卡标签、控制设备、媒体素材等说明，另起一行在 A 列写小节标题即可；更新记录留空时不会跨小节误读标签。标签和玩法类型目前仅供查看，不会自动选择游戏内标签。

### 媒体

关闭游戏多语言面板，右侧列表滚到底部。打开工具「封面 / 展示图 / 视频…」，选择文件或在文件栏Ctrl+V粘贴。展示图从第1格起按选择顺序填入；已有展示图请先手动清空。

先用「核对媒体位置」检查落点，再填写。需要调整时点「校准媒体位置」。按所选文件最多采 4 点，分别为封面、展示图第 1 格、第 2 格和视频。第 3、4 格按前两格间距推算。第 2 格须实际可见，必要时临时手动添加一张以显示第二格，采完再移除。

文件框允许独立进程或复用同一窗口；定位文件名和打开按钮，粘贴路径并打开。图片PNG/JPG/JPEG≤5MB，视频≤300MB（具体格式与编码由游戏验证）。每个文件导入后等待可调1～120秒。文件框关闭不代表导入成功，需核对缩略图及视频状态。

## 验证状态与限制

v0.3.6 便携版已由使用者在原神内实测通过。v0.3.7 的英文客户端首行与校准位置由使用者核对，英文版封面上传已实测通过。其余默认语言按相同置顶规则计算，填写前请核对游戏实际行序。

F9或停止按钮可中断；已经保存的内容不会撤销，工具会覆盖系统剪贴板。最终外层「提交」由使用者检查后手动点击。

中文和外语首行可复用同一套文字校准。工具优先读取程序旁的已保存坐标，缺少时使用内置预设。预设来自 v0.3.6 的 1920×1080、DPI 144、150% 缩放环境，按客户区比例使用于 16:9 布局。窗口大小、缩放或游戏布局变化后先检查位置。更新时保留自己的校准文件。

## 开发与测试

无需第三方依赖。在 Windows 运行：

```powershell
python -B -m unittest discover -s tests -p "test_*.py" -v
```

当前回归覆盖中英文模板、英文窗口识别、两种首行的填写顺序、坐标与两屏校准、版本弹窗、媒体文件框和 F9 中断。

打包仅在开发电脑安装构建依赖。在独立 Python 虚拟环境安装 `packaging/requirements-build.txt`，然后运行 `python packaging/build_portable.py`。构建会带上仓库中的内置预设。若要一并分发自定义坐标，可用 `--calibration-dir 目录`。`exe --self-test 报告.json` 可检查内置 Tk、DPI 感知、模板读写和预设文件。
